# 수동 테스트 시나리오 (PM6~PM8 통합)

> 브랜치 `feature/pm8-quickstart` 기준. 각 시나리오는 **단계 → 기대 결과** 체크리스트.
> 자동 게이트(pytest 108)와 별개로, 사람 눈으로만 확인 가능한 흐름·문구·감각을 검증한다.

## 0. 준비

```powershell
cd C:\Users\user\projects\harness-builder-py
git checkout feature/pm8-quickstart
python -m harness_app.qt_shell.app
```

**초기화(선택):** 랜딩/아하 기억 때문에 "첫 실행" 시나리오가 안 보이면 앱 설정을 리셋:
```powershell
# 앱의 UI 기억(테마·landing_seen·aha_seen)만 삭제 — API 키(자격증명관리자)는 안 건드림
Remove-Item -Path "HKCU:\Software\harness-builder" -Recurse -ErrorAction SilentlyContinue
```

**감지 테스트용 샘플 폴더(선택):**
```powershell
mkdir $env:TEMP\hb-sample; '{"scripts":{"build":"vite build","test":"vitest"}}' | Out-File -Encoding utf8 $env:TEMP\hb-sample\package.json
```

| B8 | (변형) 폴더 없이 만들기 | [만들고 빌더에서 확인 →] — 빌더 진입만, 파일 미생성 |

## C. 아하 시연 — "이게 하네스구나" (PM6 핵심)

| # | 단계 | 기대 결과 |
|---|---|---|
| C1 | 빌더 우패널 확인 | "하네스 없으면 ↔ 지금" 카드 3장 — `.env 쓰기: 규칙 없으면 통과(위험/주황) / 지금 hook 차단(안전/녹색)+이유` |
| C2 | "아래 규칙을 꺼보세요" 힌트 아래 **[.env 쓰기 차단] 체크 끄기** | 해당 카드가 즉시 "지금 → 통과(위험)"로 역전 + 상단에 **"방금 본 게 하네스예요" 정의 배너** 페이드인 |
| C3 | 앱 재실행 | 아하 배너가 유지(persist)되고, 이후부터 랜딩 건너뛰고 빌더 직행 |
| C4 | 시뮬 영향 없는 규칙(예: "테스트 실행 허용 · 시뮬 영향 없음") 토글 | 결과 불변 + **아하 배너 안 뜸**(거짓 인과 금지), 배지로 구분 표시 |
| C5 | 차단 카드의 "지금 → hook 차단" 줄 클릭 | 가드레일 영역으로 이동 + 원인 hook 행이 자동 펼침·스크롤 |

## D. 편집 경험 (행·용어·예시)

| # | 단계 | 기대 결과 |
|---|---|---|
| D1 | 가드레일 → hook 행 클릭 펼침 | 라벨이 한국어(검사 시점/대상 도구/동작…) + **`?` 칩** — 올리거나 클릭하면 쉬운 풀이 |
| D2 | 콤보 확인 | "검사 시점"=도구 실행 전/후/세션 시작/종료, "동작"=금지/허용/경고 (영문 PreToolUse/deny 아님) |
| D3 | "대상 도구"에 `Bash(` 입력 | 입력창 **붉은 테두리**+오류 툴팁, 우패널은 "평가 불가(패턴 오류)"로 정직 표시(패널 붕괴 없음), 힌트가 "패턴 오류를 먼저 수정하세요"로 교체 |

| D6 | 제목 수정 | 접힌 헤더 제목과 우패널 토글 이름이 **즉시 동일하게** 반영 |
| D7 | 프리셋(안전우선 등) 시드 행 확인 | 주황 "예시" 태그 + 펼치면 "그대로 두면 함께 생성됩니다…" 배너 → **한 글자라도 수정하면 둘 다 사라짐** |
| D8 | 예시 행 [복제] | 사본에도 "예시" 태그 승계 |
| D9 | 프리셋 드롭다운 전환 반복 | **깜빡임(빈 화면 프레임) 없음**, 아래 1줄 설명 갱신 |

## I. 라이브 관측 (PM9-P1 실험) — CLI 세션의 하네스 여정 실시간 추적

> 전제: Claude Code CLI 가 이 PC 에 설치돼 있어야 함. **Windows hook 실행(PowerShell) 검증이
> 이 실험의 1순위 확인 사항** — I4 에서 이벤트가 안 쌓이면 그 자체가 중요한 발견.

| # | 단계 | 기대 결과 |
|---|---|---|
| I1 | 하네스를 생성한 폴더 준비(B6 또는 G1 결과 재사용) | `<폴더>/demo/.claude/` 존재 |
| I2 | 우패널 [라이브 관측] → 폴더 선택(demo 폴더) | 상태: "아직 기록 없음 — [관측 켜기] 후…" |
| I3 | [관측 켜기(훅 설치)] | "관측을 켰습니다" + `.claude/hooks/hb-observer.ps1`·`settings.local.json` 생성(개인 설정 — 팀 하네스 무영향) |
| I4 | 그 폴더에서 터미널 열고 `claude` 실행 → 아무 요청(예: "이 폴더 파일 목록 보여줘") | 관측 창 타임라인에 **"세션 시작 — 컨텍스트 로드" → "요청 수신: …" → "도구 실행 전 …"** 이 실시간으로 흐름 |
| I5 | Claude 에게 ".env 파일에 TEST=1 써줘" 요청 | 타임라인에 **"도구 실행 전 Write: .env → 매칭 '.env 쓰기 차단' (hook 차단)"** 굵게 표시 — 카드 매칭이 육안 확인됨 |
| I6 | 규칙에 없는 명령(예: `echo hi`) 요청 | "→ 매칭 규칙 없음 (통과)" — **보강점 후보가 눈에 보임** |
| I7 | [관측 끄기] | hb-observer 등록·스크립트 제거, 기존 개인 훅은 보존 |
