# 3-A 계획서 — 시뮬 ↔ 산출물 ↔ 런타임 정합 (승인 요청)

> 상태: **승인 대기**. 작성 2026-07-24. 대상 = 로드맵 `docs/ROADMAP_CC_FIRST.md` 티어3 3-A.
> 이 문서의 모든 수치·판정은 **추측이 아니라 실측**이다(재현 절차 첨부).

## 0. 한 줄 요약

버클의 중심 약속 **"화면에서 막힌 것 = 산출물에서 막힘"** 을 처음으로 참으로 만든다.
실측 결과 3-A 는 **위험도가 다른 3조각**으로 갈리며, 그중 둘은 frozen 을 건드리지 않는다.

## 1. 왜 지금인가 (근거)

전략 분석(2026-07-24, 다중 에이전트 + 적대 검증)이 이 갭을 **blocking** 으로 지목했다:

> "이 갭은 '검증 부재'보다 나쁘다. 검증 부재는 사용자가 모른다는 것을 알게 하지만,
> 시뮬-실제 불일치는 사용자에게 근거 없는 확신을 심는다."

로드맵 원칙도 같다 — *"해자가 거짓말하는 상태에서 커버리지를 쌓으면 거짓을 복리로 키운다."*
1-C·2-B·2-C 로 **탐지·표면화**는 끝났고, 남은 것이 **근본 해결**이다.

## 2. 실측 — 무엇이 실제로 깨져 있나

### 2-1. `glob_to_regexp` `**` 축소 결함 (재현 완료)

`harness_core/sim/simulate.py:11-15`. `**/` → `(?:.*/)?` 를 삽입한 **뒤에** `*` → `[^/]*` 를
치환해, 방금 삽입한 `.*` 의 `*` 까지 오염된다 → `.[^/]*` = "정확히 한 단계".

| glob | 현재 생성 정규식 | `sub/dir/.env` | 실제 bash 훅 |
|---|---|---|---|
| `**/.env*` | `^(?:.[^/]*/)?\.env[^/]*$` | **통과(오판)** | 차단 |
| `**/.git/**` | `^(?:.[^/]*/)?\.git/.[^/]*$` | `x/y/.git/hooks/pre` **통과(오판)** | 차단 |
| `.claude/**` | `^\.claude/.[^/]*$` | `.claude/a/b` **통과(오판)** | 차단 |

**방향이 과소 매칭** — 시뮬이 현실보다 **덜** 막는다(사용자에게 "안 막힌다"고 잘못 안심시키는
쪽은 아니지만, 규칙을 더 넣게 만들거나 Lv4 판정을 왜곡).

### 2-2. hook `action`/`path_glob` 미직렬화 (발견 A)

`harness_core/export/export_ir.py:76-85` 는 `matcher` + `command` 만 기록한다.
`action(deny)`·`path_glob` 은 **simulate 전용 메타**로 남아 산출물에 없다 →
실제 차단 여부는 **오직 스크립트 exit code** 가 결정한다.

- 프리셋·카탈로그 훅은 스스로 `exit 2` 를 하므로 **결과적으로** 맞다.
- 그러나 `enforcement.py:45-52` 의 승격 스텁은 `# TODO ... exit 0` → **금지로 표시되지만 안 막는다.**
  (2-B `sec-hook-no-enforce` 가 지금 이걸 경고로 잡고 있다 — 탐지는 되나 해결은 아님.)

## 3. 위험도 분해 — 실측이 바꾼 그림

로드맵은 3-A 전체를 "frozen 변경"으로 분류했으나, **측정 결과 셋으로 갈린다.**

| 조각 | 내용 | frozen 골든 영향 | 위험 |
|---|---|---|---|
| **3-A-1** | `glob_to_regexp` 결함 수정 | **없음(실측)** | 낮음 |
| **3-A-2** | `action`+`path_glob` → exit-2 가드 코드젠 | **있음** (훅 스크립트 본문 포함) | 높음 → 결정 필요 |
| **3-A-3** | `enforcement.promote` 스텁을 실제 가드로 | 3-A-2 에 종속 | 중간 |

### 3-A-1 이 frozen 무영향인 이유 (실측)

frozen `simulate.json` 의 시나리오는 **루트 `.env`** 뿐이다(`sub/dir/.env` 없음).
수정 전후 시뮬 결과가 **바이트 동일**함을 확인했다.

```
수정안 케이스: 12/12 통과
골든 == 수정 전: True
골든 == 수정 후: True   → frozen simulate.json 바이트 불변
```

또한 기존 `tests/test_simulate.py:5-9` 는 **매칭 결과만** 단언하고 정규식 문자열은 단언하지 않아,
패턴 표현이 바뀌어도 깨지지 않는다.

### 3-A-2 가 frozen 을 건드리는 이유

frozen `export_preset.json`·`assemble_*.json` 은 `.claude/hooks/block-secrets.sh` 의
**본문 전체**를 담는다. 가드를 코드젠해 넣으면 바이트가 바뀐다. 우회 불가 —
실제 Claude Code `settings.json` 스키마에는 `path_glob` 을 담을 자리가 없어, 경로 조건은
**스크립트 안에서** 검사할 수밖에 없다.

## 4. 설계 — "단일 생성기"를 어떻게 만들 것인가

핵심: 시뮬의 판정과 스크립트의 차단이 **같은 정규식 한 벌**에서 나오게 한다.

### 4-1. 정규식 방언 문제와 해법 (실측)

Python 전용 `(?:...)` 는 **POSIX ERE(grep -E)에 없다** — 그대로 내보내면 스크립트가 매칭에 실패한다.
비캡처를 포기하고 **평범한 그룹 `(.*/)?`** 로 생성하면 양쪽에서 동일하게 동작한다.

```
ERE(grep -E)  pass=11 fail=0
Python re     pass=7  fail=0
확인: Python 전용 (?:...) 는 grep -E 에서 매칭 실패 → 호환 문법 필수
```

→ `glob_to_regexp` 를 **양쪽 호환 문법으로 생성**하도록 고치면(3-A-1 과 동시 해결),
그 산출 문자열을 스크립트에 그대로 심어 **문자 그대로 단일 소스**가 된다.

### 4-2. 코드젠 형태

`action="deny"` + `path_glob` 인 훅에 대해, 사용자 본문 **앞에** 가드를 삽입한다
(본문은 보존 — 카탈로그 훅처럼 이미 완결된 스크립트를 덮어쓰지 않기 위함).
jq 없이 grep 기반(우리가 이미 검증·표준화한 방식).

```bash
#!/usr/bin/env bash
# [버클 자동 생성 가드] path_glob: **/.env*   ← 시뮬 판정과 동일 규칙
input=$(cat)
__p=$(printf '%s' "$input" | grep -oE '"file_path"[[:space:]]*:[[:space:]]*"[^"]*"' \
      | head -1 | grep -oE '"[^"]*"$' | tr -d '"')
__p="${__p//\\\\//}"; __p="${__p//\\//}"
if printf '%s' "$__p" | grep -qE '^(.*/)?\.env[^/]*$'; then
  echo "차단: 이 경로에는 쓸 수 없습니다 (**/.env*)" >&2; exit 2
fi
# ↓ 사용자가 작성한 본문 (그대로 보존)
```

### 4-3. 남는 한계 (정직 표기 — 이번 범위 밖)

- 가드도 bash 라 **Windows 에 git-bash 가 없으면 여전히 미실행**이다. 그건 1-C(앱 게이팅)·2-C(lint)가
  이미 표면화하며, pwsh 병행 생성은 별도 항목으로 남긴다.
- `matcher_tool` 은 `settings.json` 의 `matcher` 가 이미 담당 → 스크립트에서 재검사하지 않는다.

## 5. **결정이 필요한 지점** — frozen 을 어떻게 다룰 것인가

여기에 **문서 간 모순**이 있어 사용자 판단이 필요하다:

- `ADR-0012`: frozen 은 **"영구 불변 — 어떤 커밋도 재생성·수정 금지"**
- `ROADMAP` 티어3: **"사용자 명시 승인 + 골든 재생성"**

두 안 중 하나를 골라야 한다.

### 안 A — opt-in 파라미터 (ADR-0012 준수, frozen 불변) ★ 권장

`export_ir(ir, enforce_hooks=False)` 를 추가하고 **기본값은 현행 유지**, 앱은 항상 `True` 로 호출.
ADR-0012 가 명시한 길과 **정확히 일치**한다:

> "신규 코어 ADD 는 기본 호출 결과를 바꾸지 않는 형태(**opt-in 파라미터**, 신규 모듈)여야 한다."

- 장점: frozen 무손상, 롤백이 플래그 하나, ADR 개정 불요, 승인 리스크 최소.
- 단점: 기본 경로(골든이 지키는 것)와 앱 경로(사용자가 받는 것)가 갈린다 →
  **완화**: `gen_golden_ext.py` 에 `export_enforced` 생성기를 등록해 **extended 골든으로 신 경로도 회귀 보호**
  (ADR-0012 가 설계한 그대로의 사용법). 기본값 전환은 **나중에 별도 결정**.

### 안 B — frozen 1회 재박제 (ADR-0012 개정)

새 ADR(`ADR-0014`)로 ADR-0012 의 "영구 불변"을 개정하고, frozen 3개 파일을 재생성.

- 장점: 기본 경로가 곧 진실 — 갈림 없음.
- 단점: TS 파리티 게이트를 영구히 잃는다. 되돌리기 어렵고, "골든을 갱신해도 되는가"가
  다시 협상 가능해지는 규율 리스크(ADR-0012 가 막으려던 바로 그것).

## 7. 검증 방법 (계약의 실증)

이번 작업의 성패는 **"시뮬 = 산출물 = 런타임"이 한 케이스에서 동시에 참**임을 보이는 것이다.

1. **정합 실증 테스트(신규)** — `sub/dir/.env` 하나로 3자를 동시 확인
   - 시뮬: `simulate(...)["outcome"] == "blocked-by-hook"`
   - 산출물: 생성된 스크립트에 가드가 실제로 포함
   - 런타임: 그 스크립트에 가짜 payload 를 파이프 → **exit 2** (우리가 확립한 로컬 exit-code 검증 방식)
2. **frozen 골든 diff 0** — `git diff --stat tests/golden/frozen/` 가 비어야 함(안 A 기준)
3. **오탐 회귀** — `src/app.js`·`environment.ts`·`.gitignore` 등 비대상 경로가 통과(exit 0)
4. **전 프리셋 스모크** — 5종 export → 스크립트 문법 검사(`bash -n`) 전건 통과
5. **pytest 전량 GREEN + ruff clean**
