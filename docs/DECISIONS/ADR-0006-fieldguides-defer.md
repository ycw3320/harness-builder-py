# ADR-0006: field_guides 데이터 외부화 + 소비처(PM3) 이연

- **상태:** 수락 (2026-06-24)
- **맥락:** 필드 가이드("외부 LLM에 이렇게 요청하세요" 템플릿·예시)는 골든 게이트와 무관한 **UI 데이터**이며, 소비처(가이드 위젯)는 PM3다.
- **결정:** `harness_core`가 아니라 **`harness_app` 계층(또는 `guides/`)에 데이터로 배치**한다. 콘텐츠 본문 작성은 소비 시점(PM3)에 한다. (이 데이터가 §0.6 안내형 누적 흐름의 프롬프트 원천)
- **근거:** 코어 순수성 유지(가이드는 UX 자산). 미사용 데이터를 코어에 미리 넣지 않는다.
- **영향:** PM2 코어/게이트에 영향 없음. PM3에서 가이드 데이터 + 위젯(B6)을 함께 구현.
