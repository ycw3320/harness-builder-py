# ADR-0011: 초심자 직관화 — 하네스 "아하" 재설계 (결과의 차이로 정의)

- **상태:** 수락 (2026-06-26)
- **맥락:** 사용자 피드백 "아직 어려워." PM1~5로 기능은 완비됐으나 북극성("CC 초심자도 쉽게 + 하네스가 뭔지 직관 이해")에 미달. 다각도 검증(워크플로 29 에이전트: 현업/지망 개발자 페르소나 4명 첫 실행 시뮬 → 6렌즈 독립 재설계 → 3인 패널 18심사 → 종합)에서 **페르소나 4명 전원이 "아, 이게 하네스구나" 도달 실패**. 공통 원인(만장일치): ① 빈 시작(minimal) 기본 → 차단 장면 못 봄 ② before/after 가치 시연 부재 ③ "하네스" 정의·전문용어 무설명 노출.
- **결정:** **"설명 대신 결과의 차이로 정의한다"**를 단일 핵심 메커니즘으로 채택. 6렌즈 중 최상위권(시뮬레이터-인터랙티브 43 ≈ 아하-가치우선 42.7)을 종합 — **결정론 시뮬레이터(해자)를 우측 부속에서 1급 시연 패널로 승격**.
  - **before/after 2열:** 빈 IR(규칙 없음) vs 현재 IR을 같은 시나리오로 `simulate` 2회 → "규칙 없으면 통과(위험) ↔ 지금 차단(안전)" 대비. **코어 무수정**(빈 IR은 앱 계층 생성, `view_model.sim_compare`). 버려지던 `SimVM.reason`을 노출.
  - **체감 먼저, 정의 나중:** 사용자가 '켜진 규칙'을 토글로 끄면 우열이 즉시 무너지는 인과를 체감 → **그 직후** "방금 본 게 하네스예요" + 안전벨트 정의 페이드인. 텍스트 벽 환영 모달 제거.
  - **인과 점프:** 차단 줄 클릭 → 원인 컴포넌트로 이동·펼침(`after_blocked_by`).
  - **용어 2단 풀이:** 필드 라벨은 쉬운 말 + 호버 dev 툴팁("(?)"). Hook 시점 등 콤보 한글 표시·원시값 분리(`option_labels`/`itemData`). `GLOSSARY` 대신 `FieldSpec.tip`로 인-컨텍스트 풀이.
  - **첫 화면 = 작동하는 예시:** 기본 프리셋 `minimal → safety-first`(1줄). 프리셋이 넣은 시드엔 "예시예요, 지워도 됩니다" 배너(편집 시 in-place 숨김 → 포커스 보존).
  - **종결 안내:** export 후 "다음 단계"(폴더 두기 → `claude` 실행 → 차단 실제 적용) + 폴더 열기.
- **앵커 비유:** **안전벨트**(치환 아닌 병기 — 실제 용어 항상 동반). `HARNESS_DEFINITION`/`HARNESS_AHA` 단일 출처(guides.py)로 spaced repetition.
- **배치 제약(검증된 코드 사실):** AHA 시연 패널은 **우측에 둔다**. `_signature`가 pattern/body 미추적 → 중앙 상단 배치 시 편집 갱신 누락. `_rebuild_right`는 항상 실행되므로 토글 역전이 **추가 배선 0**.
- **정직 프레이밍:** before 좌열은 "규칙 없으면"(빈 IR) — "완전 무방비" 과장 금지(해자 신뢰 보존).
- **해자·골든 불변:** 결정론 시뮬레이터·lint **LLM 0회** 유지, 코어 무수정 → **골든 게이트 불변**. 오프라인 기본 보존.
- **이번 제외(descope):** 자유입력 샌드박스(휴리스틱 오분류가 결정론 신뢰 훼손), 모드 탭 분리, `rm -rf` 신규 시나리오(골든 재박제 회피), 위험도 라벨 신규 데이터, 확장 비유 일러스트.
- **영향:** `harness_app/view_model.py`(sim_compare·sim_rules·FieldSpec.tip/option_labels), `harness_app/qt_shell/app.py`(우패널 2열·토글·점프·아하 배너·6계층 캡션·예시 배너·콤보 한글·export 가이드), `harness_app/guides.py`(정의 상수·흐름 캡션). 신규 `tests/test_sim_compare.py`. pytest 66→71 GREEN. 관련 [[ADR-0001]](코어 순수), [[ADR-0008]](테마·시그니처 라우팅), [[ADR-0009]](동적 폼·field-spec).
