# ADR-0005: FS 병합 디폴트 = 비파괴(SKIP_EXISTING) + dry-run

- **상태:** 수락 (2026-06-24)
- **맥락:** 이 도구의 핵심은 사용자의 실제 프로젝트 폴더에 `.claude/`를 생성/병합하는 것이다. 기존 파일을 덮어쓰면 사용자 자산이 손실될 수 있다.
- **결정:** `write_tree`의 기본 전략은 **`SKIP_EXISTING`(기존 파일 보존, 덮어쓰기 안 함)** + **dry-run 필수**(쓰기 전 무엇이 생성/스킵/충돌인지 미리보기). 덮어쓰기는 사용자가 **명시 선택**(`OVERWRITE`) 시에만. `BACKUP`(.bak 보존)도 선택지로 제공.
- **근거:** 전역 안전 원칙(비가역 작업 전 비파괴 우선). 초심자 대상이라 "실수로 덮어씀"을 구조적으로 차단해야 한다(북극성).
- **영향:** `write_tree(..., strategy=SKIP_EXISTING)`, 전수검증 후 기록·경로 traversal 차단·멱등. 충돌은 데이터로 반환하고 결정은 UI(B5c)가 한다.
