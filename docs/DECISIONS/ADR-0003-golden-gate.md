# ADR-0003: 골든 바이트-동일 게이트 (TS 산출 동치)

- **상태:** 수락 (2026-06-24)
- **맥락:** 코어를 TS에서 Python으로 직역하면 정규식·glob·JSON 직렬화의 미세한 시맨틱 차이로 산출물이 어긋날 수 있다.
- **결정:** TS 웹(frozen 참조)이 만든 export/assemble/simulate/lint 산출을 `tests/golden/`에 박제하고, Python 산출이 **경로 집합 + 경로별 내용 바이트 동일**인지 pytest로 강제한다. (리스트 *순서*는 로케일 의존적이라 비교하지 않음 — Python 결정론 정렬 사용)
- **근거:** 포팅 시맨틱 회귀를 자동 차단. 순서는 폴더 직접쓰기에 무의미하므로 내용·집합만 보장하면 충분.
- **영향:** 코어 리팩터링 시 골든은 **갱신하지 않는다**(의도 변경일 때만 독립 커밋). 골든 재생성: TS repo에서 `npx -y tsx scripts/gen-golden.ts <out>`.
