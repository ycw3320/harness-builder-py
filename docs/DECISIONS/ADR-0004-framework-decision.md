# ADR-0004: GUI 프레임워크 판정 = 에이전트 정량 + 사용자 최종

- **상태:** 수락 (2026-06-24) — *결정 대상(Flet vs PySide6)은 PM2에서 확정*
- **맥락:** Flet(모던룩·1인 속도 강점)과 PySide6/Qt(표현력 천장 강점)는 트레이드오프가 명확하다. 본 앱 UI(폼·리스트·문서뷰)는 Flet 약점에 거의 해당하지 않는다.
- **결정:** PM2에서 **양쪽 최소 셸(S1~S6)을 모두** 만들고, 루브릭(M1~M8, 가중 100)으로 판정한다. **정량 항목(36px 밀도·색점·LOC/시간·패키징)은 에이전트가 채점**, **모던룩(M5)·최종 선택은 사용자**가 스크린샷으로 결정한다.
- **근거:** 픽셀·LOC은 객관 측정 가능, 모던룩은 주관 — 역할 분리. 코어가 GUI 무관(ADR-0001)이라 판정 비용은 UI 층에 국한.
- **영향:** 폐기 갈래는 `_archive/`로 격리(삭제 아님). PySide6 고정(PyQt6 GPL 회피).
